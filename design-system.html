Design System / Componentes

Decisiones visuales y componentes reutilizables del portafolio. Todo lo que ves aquí usa las mismas clases y variables CSS que el sitio. Cambia el tema para ver ambos valores.

Colores

Cada muestra lee su valor directamente de la variable CSS del tema activo.

  • Primary--color-primary#0e6e6a
  • Secondary--color-secondary#d99a1e
  • Background--color-background#f3f5f4
  • Surface--color-surface#ffffff
  • Text--color-text#14201f
  • Text muted--color-text-muted#56615f
  • Border--color-border#d5dcda
  • Error--color-error#b42318
  • Success--color-success#1f7a3e

Espaciado

Escala basada en rem. Se usa para padding, margin y gap en todo el sitio.

  • --space-xs0.25rem
  • --space-sm0.5rem
  • --space-md1rem
  • --space-lg2rem
  • --space-xl3rem
  • --space-2xl5rem

Radios: --radius-sm (0.375rem) para botones e inputs, --radius-md (0.75rem) para cards, --radius-pill para tags y chips. Sombra: --shadow-card.
